# BetterOrgBrowser Release Notes

Public-facing release notes for BetterOrgBrowser.

Use DEVLOG.md for session-level development history. Use this file for concise version summaries.

## v0.0.1

Initial working MVP foundation.

### Added

- VS Code extension scaffold.
- Better Org Browser activity bar view.
- Salesforce org picker.
- Live metadata browsing for Apex Classes, Flows, Custom Objects, and Object Fields.
- Field detail inspection.
- Copy API Name command.
- Add to Manifest command.
- package.xml preview and write support.
- Retrieve Manifest command.

### Known Limitations

- Manifest selections are not yet visible as a dedicated tree section.
- Permission Sets are placeholder-only.
- Retrieve output is raw JSON.
- No caching or dependency analysis yet.
